The content of this repository reflects work developed in Python, MATLAB, and R, covering quantitative finance, data management, and machine learning applications. It includes material from my Master’s thesis, as well as projects and assignments completed during my coursework.

The projects combine theoretical financial concepts with practical implementation. They involve working with financial datasets, building quantitative models, and performing numerical simulations. Particular attention is given to data handling, model implementation, and performance evaluation.

Several scripts focus on option pricing and stochastic processes, while others illustrate broader quantitative methods used in finance. The work integrates data manipulation, statistical modeling, and computational techniques across different programming environments.

The objective of this repository is to present clear and structured implementations that connect mathematical theory with applied coding practice. The emphasis is on transparency, readability, and a step-by-step approach to translating financial models into reproducible code.
